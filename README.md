# 🗳️ Decentralized Voting System

## 📖 Project Description
The **Decentralized Voting System** is a blockchain-based application that allows transparent and tamper-proof voting. Each voter can cast one vote, and all votes are securely recorded on the Ethereum blockchain to ensure fairness and integrity.

## 🌍 Project Vision
Our vision is to revolutionize the voting process by leveraging blockchain technology to create a **secure**, **transparent**, and **trustless** election system—eliminating fraud and ensuring that every vote counts.

## ✨ Key Features
- **Secure Voting:** Each wallet address can vote only once.
- **Transparent Results:** Anyone can view the candidate list and votes on-chain.
- **Admin Control:** Only the admin can register candidates or close the voting session.
- **Immutable Records:** All votes are stored permanently on the blockchain.

## 🧩 Smart Contract Overview
The `Project.sol` contract includes:
1. `addCandidate()` – Admin adds candidates to the election.
2. `vote()` – Voters cast their votes once.
3. `getWinner()` – Returns the leading candidate after voting ends.
4. *(Optional)* `closeVoting()` – Ends the voting session by the admin.
